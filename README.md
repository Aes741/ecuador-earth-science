# Ecuador: A Country Shaped by Earth

Static website for the PS 120 Earth Science country project.

## Pages

- `index.html` — Home page and project overview
- `about.html` — Personal connection and reflection prompts to personalize
- `maps-location.html` — Maps, Location, and Cartographers
- `tectonics.html` — Plate Tectonics, Earthquakes, and Volcanoes
- `weathering-erosion.html` — Weathering, Mass Wasting, and Erosion
- `water-coasts.html` — Fluvial Processes, Oceans, and Coastlines
- `climate-biomes.html` — Climate Controls, Biomes, and Climate Change
- `references.html` — APA-style references

## Project structure

- `assets/css/styles.css` — shared responsive styles
- `assets/js/navigation.js` — accessible mobile hamburger navigation
- `assets/images/kitty-working.png` — ChatGPT-generated placeholder image

## Preview

Open `index.html` in a browser. The site uses plain HTML and CSS, so it does not need a build step. All page and asset paths are relative, which makes the site compatible with GitHub Pages project sites.

## Publish with GitHub Pages

1. Push the contents of this folder to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Submit the published `https://<username>.github.io/<repository>/` URL for the assignment.

Before submission, test the published pages, navigation, responsive layout, images, and external links on both a phone-sized and desktop-sized viewport.
